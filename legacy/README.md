## 复刻范围判定

### ✅ 进入复刻范围：`xiangsudian.py`

这是 Classic 旧算法的唯一考古对象。它的整条链路严格产出**只有黑白两种取值的 3 通道图像**：

- 输入读取 → 可选直方图均衡 → 缩放 → 降采样 → 双层分级阈值赋值 → 最近邻放大 → 输出
- 全程没有中间灰度、没有平滑插值、没有色彩混入，是纯粹的二值化管线。

**本项目 Classic 算法 = 严格复现该脚本的既有行为，包括其中"看起来不标准"的细节**（详见根目录 `docs/` 后续文档）。不做修正、不做优化。

### ❌ 不进入复刻范围：`xiangsudian2.py`

它与 `xiangsudian.py` 共用同一套参数与主体结构，但引入了三项**非二值**改动：

1. 网点灰度值由 `0` 改为 `a*a/t`（`t` 为灰度阈值），产生黑白之间的连续灰阶；
2. 网点排布由单一 `(偶数行, 偶数列)` 网格扩展为 `(偶数, 偶数)` + `(奇数, 奇数)` 双网格交错；
3. 输出侧追加 `gama_transfer(..., 4)`、`skimage` 高斯滤波、USM 锐化与 `matplotlib` 保存。

第 3 项实际上是一段**独立的后处理实验尾巴**，且存在明显缺陷（`gama_transfer` 返回值未赋回 `img_r`，被计算后直接丢弃；`plt.savefig` 仍保存 `img_out` 的 `figure(2)` 而非 `output_file`；`gama_transfer` 内含一档 9 空格缩进的不规则代码）。这些缺陷**记录在案但不作为复刻输入**——该脚本整体不进入正式算法范围。

### ❌ 不进入复刻范围：`xiangsudian3.py`

这是一条与二值路线无关的**彩色化旁支**，处理逻辑完全不同：

- 直接以 `INTER_NEAREST` 生成固定棋盘网点遮罩，网点尺寸即参数 `s`（默认 30，不走缩放/降采样流程）；
- 网点处不落独立的二值灰阶，而是按亮度做 `255 - t*(255 - c)` 的比例混色，`t ∈ [0,1]` 控制染色强度；
- 输出是**彩色图像**，不是黑白二值图。

它与项目边界（严格黑白二值伪像素图）直接冲突，**不纳入正式算法范围**，仅作为网点遮罩思路的历史参考。
